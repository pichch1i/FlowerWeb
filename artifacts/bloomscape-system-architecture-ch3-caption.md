## ข้อความประกอบแผนภาพสำหรับบทที่ 3

**ชื่อรูป:** รูปที่ 3.x แผนภาพสถาปัตยกรรมระบบเว็บไซต์ Bloomscape และระบบ Interactive Media

ในช่วง Open House ระบบแบ่งเป็น 2 ชุดการทำงาน ชุดที่ 1 คือ Bloomscape.ths1/Supabase/TouchDesigner/โปรเจกเตอร์ โดยเว็บไซต์รับข้อมูลผู้เล่นและคำตอบแบบสอบถามจำนวน 7 ข้อ แล้วส่ง JSON ไปยัง Supabase Edge Function เพื่อตรวจสอบและบันทึกลงฐานข้อมูล PostgreSQL เมื่อบันทึกผลสำเร็จจะสร้าง event ให้ TouchDesigner เรียกอ่านผ่าน API และประมวลผลภาพสำหรับโปรเจกเตอร์ โดยมี Orbbec ทำหน้าที่รับสัญญาณภาพ ตำแหน่ง และการเคลื่อนไหวเพื่อส่งให้ TouchDesigner ชุดที่ 2 คือ Ultrasonic Sensor/Arduino/Ableton/TouchDesigner/จอทีวี โดย Ultrasonic Sensor ตรวจวัดระยะ ส่งค่าผ่าน Arduino ไปยัง Ableton และ TouchDesigner เพื่อควบคุมและแสดงผลภาพกับเสียงบนจอทีวี

**ตำแหน่งแนะนำ:** แทรกเป็นหัวข้อย่อยในบทที่ 3 หลังส่วนอธิบายการพัฒนาและการเชื่อมต่อระบบ ก่อนเข้าสู่รายละเอียดการทดสอบหรือผลลัพธ์ของระบบ
